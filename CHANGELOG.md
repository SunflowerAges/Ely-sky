# Changelog

All notable public changes to Ely-sky are documented here.

## 1.0.0

Initial public release.

### Added

- Private Elytra time-trial courses
- In-world course authoring workflow
- Checkpoint rings and route guidance
- Boost Portals
- Personal Best and Server Best ghosts
- Rival and leaderboard-player ghosts
- Casual and Competitive course presentation
- Revision-aware records and leaderboards
- Administrative test, validation, diagnostics, record moderation, and repair tools
- Optional loan equipment
- Optional PlaceholderAPI, MiniPlaceholders, Vault, and LuckPerms integrations
- Public Bukkit service API and race lifecycle events
